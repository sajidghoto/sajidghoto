## 🚀 Featured Projects

### [SciFact Retrieval & Generation Evaluation](https://github.com/sajidghoto/scifact-retrieval)

*Python · FastAPI · PostgreSQL/pgvector · bge-base · Qwen3-4B · Next.js*

Solo project. Compares BM25, dense and hybrid retrieval on BEIR SciFact, with cited-answer generation evaluated on 300 held-out queries. Fusion weight was tuned on training queries only, then tested once and checked with a paired bootstrap. Hybrid reached nDCG@10 0.759 vs 0.741 dense and 0.662 BM25 (+0.019 over dense, 95% CI 0.004 to 0.033).

### [Study Assistant](https://github.com/sajidghoto/study-assistant)

*Python · FastAPI · React · scikit-learn · sentence-transformers · ChromaDB · Gemini API*

Solo project for an AI course. Intent-aware RAG assistant for PDF lecture notes. Compared TF-IDF vs MiniLM retrieval on 72 annotated questions and found that 97% of chunks exceeded the encoder's token limit. A Logistic Regression intent classifier (weighted F1 0.89 on 19 held-out queries) routes each query to an intent-specific Gemini prompt.
